# Langy Reader

Langy Reader is a self-hosted EPUB and PDF library for language learning. Organize books into categories, hover or tap for word help, and generate a summary of the page you are reading.

See it in action at https://langy.srtw.win | Screenshots at https://imgur.com/a/wzt5KDB

## Series, document conversion and connected libraries

Import or edit a book to set its **Series** and optional **Book number** (fractional numbers such as 1.5 are supported). Filter by series or choose **Series order** to read in sequence. Series metadata survives OCR replacement.

EPUB and PDF open directly, up to the existing 120 MiB self-hosted limit. **TXT (UTF-8), Markdown, HTML/XHTML, DOCX, ODT, RTF and FB2** can be uploaded for background conversion to EPUB, up to **30 MiB** (20 MiB in the public demo). Conversion preserves text, headings and supported embedded raster images; complex layouts can change. External/local linked images, active content and source-provided converter options are removed. PDF stays PDF; use OCR for scanned PDFs. MOBI, AZW/KFX, DRM, spreadsheets, presentations and image archives are not offered as automatic conversions. Only upload documents you are entitled to use.

The reader image includes a checksum-pinned official **Pandoc 3.14** static binary for amd64/arm64. It runs separately with sandboxing, a 512 MiB managed-heap cap, a two-minute timeout, compressed-container expansion limits and no inherited provider credentials. Native Node installations should run `sudo sh scripts/install-pandoc.sh` first, or set `LANGY_PANDOC_BIN` to that static binary. The converter is GPL v2 or later; its license is in [licenses/pandoc-GPL-2.txt](licenses/pandoc-GPL-2.txt), and the image includes upstream copying conditions and corresponding-source links in `/usr/local/share/doc/langy-pandoc/`.

In **Settings → Book sources → Kavita**, paste your personal OPDS URL from Kavita's **User settings → 3rd Party Clients**. The URL must be reachable from the Langy container; use a LAN address or a shared Docker-network service name rather than `localhost` for another container. Optional HTTP Basic credentials are supported. Save and test, then **Browse Kavita** from settings or Import book. Browse collections, search when the feed provides OpenSearch, and queue EPUB/PDF acquisitions into your own folder. This connection only browses and imports; it does not change Kavita or synchronize reading progress. Each Langy account has its own private connection. Feed keys and credentials are stored server-side with restricted file permissions, never returned in catalogue JSON, and never forwarded to another origin. Configure Kavita's hostname so its feed links use the same origin as the URL you saved.

Cover imports and accepted OCR scans close their dialogs immediately; follow progress, retry errors, or reopen Details in **Process queue**. Conversions and Kavita downloads also run there, continue when their dialogs close, and refresh the library when finished. Conversion source files are removed after success, failure or cancellation; upload the original again to retry a failed conversion. Web/Kavita downloads can be retried from the queue.

## Optional reading profile

Open **Reading profile** in the library sidebar or the mobile library menu. Its responsive graph shows actual vocabulary first encounters, daily familiar-vocabulary observations, or input-hour observations. Mandarin uses **Han characters**; other languages use **lemmas**. Counts are kept separate by language, and your configured **L1 is excluded from all profile API results, graphs, estimates and selectors**, including regional/script variants.

Add estimated **input hours outside Langy**, excluding time already tracked in the app, and optional reading/listening comprehension checks. The page combines this context with repeated exposure, your familiarity threshold, books encountered and active reading hours. The broad ACTFL-inspired ranges come from the comprehension checks; vocabulary counts and hours do not automatically award a level. There is no validated universal conversion from hours or lemma/Han-character counts to OPI/CEFR proficiency. Reading/listening self-estimates do not measure speaking or writing. The page links to the [ACTFL overview](https://www.actfl.org/proficiency-guidelines-overview) and [Nation's English coverage research](https://www.lextutor.ca/cover/papers/nation_2006.pdf); English word families are not equated to lemmas or Han characters. No AI calls or paid tokens are needed for this page.

First-encounter history can be reconstructed from saved exposure records. Familiar-vocabulary and input-hour observations begin when you first use the profile, without inventing an earlier curve. They are saved to your account and survive restarts; demo data expires with the session. Changing L1 hides its stored history without erasing it, and changing the exposure threshold filters the familiar-vocabulary graph to matching observations. This optional page adds no streaks, scores or ranking to the library.

## Run it on your server

On a Docker host with Docker Compose installed:

```bash
git clone https://github.com/Attach7830/Langy-Reader.git
cd Langy-Reader
docker compose up -d --build
```

Open `http://YOUR_SERVER_IP:8088`. The first build downloads Qwen3 4B Instruct (about 2.5 GB of model weights) into the Ollama image. Subsequent starts use the baked-in model and can run offline. CPU inference works. As a starting point for the bundled model, allow about 8 GiB of available RAM and 12 GB of free disk space for the images and build cache.

The default listener is available on your LAN. Set `READER_BIND=127.0.0.1` in a copy of `.env.example` named `.env` if you prefer a local reverse proxy. Configure `READER_USER` and `READER_PASSWORD` there to enable sign-in. Use HTTPS when forwarding password-protected traffic beyond the server.

Books, categories and reader preferences live in the data volume. Reading preferences follow each reader account across browsers and devices: appearance, language choices, pinyin, shortcuts, audio controls and selected recordings. The first browser imports its existing preferences into an empty account; later browsers load the saved account choices. Local caching keeps reading available offline and retries changed preferences when connected. Device names and the device’s progress-sync toggle stay local; reading positions use the separate progress-sync feature. Demo preferences are private to each expiring visitor session. Back up the data volume to preserve uploaded files, the catalog and account preferences.

Selecting an EPUB or PDF in **Import book** fills in its title, author and primary language from embedded metadata. When no language is declared, Langy samples readable text to estimate it. A missing title falls back to the filename; an undetectable language defaults to Spanish. Review or change the fields before importing, or use **Book details** (the pencil on a library card) afterward. Blank fields request automatic details; saved details are retained when the file supplies none. Your edits take precedence over automatic suggestions; language folders still apply their configured language. Detection runs locally without an AI API. Scanned or locked PDFs and files with incomplete metadata may need manual details. Books use one primary language by default; enable **Multiple languages in this book** to detect passages among explicitly selected languages.

The stack also includes a local `language` service for lemma analysis and audio alignment. Its first build installs Spanish, English and Portuguese spaCy models, lookup data for additional supported languages, and the multilingual Whisper **small** model. These models run offline after the build and require no paid API. Set `READER_WHISPER_MODEL=base`, `small`, `medium` or `large-v3` in `.env` before building to choose the recognizer; larger models require more download space, RAM and CPU time. Rebuild both `language` and `reader` after changing it. Narration connects to your existing Kokoro server.

For NVIDIA hosts, [optional GPU alignment](docs/gpu-alignment.md) moves Whisper recognition to CUDA while keeping your existing Kokoro setup. Run `sudo bash scripts/enable-gpu-alignment.sh` after updating; it builds and checks real local inference before briefly restarting the reader and language service. Runtime logs show the actual device and time spent aligning each audio chunk. Keep `compose.gpu.yaml` in future language-service update commands.

## Accounts and shared books

Set `READER_USER` and `READER_PASSWORD` in `.env` to enable accounts. On the first start after this update, that existing account becomes the instance administrator and keeps its library, categories, reader preferences, progress and reading history. There is no public registration. Open **Settings → Account** to create reader or administrator accounts, disable access, or reset a password. New passwords must contain 15–256 characters. Each user can change their own password there. Password changes, resets and disabling an account end its existing sessions.

Every new account starts with an empty, private library. In **Import book** or **Edit book details**, use **Share with** to choose **Only me**, **Everyone on this server**, or **Selected users**. With **Selected users**, check the accounts that should have access, then save. Recipients can find the book in their library and OPDS feed, read and listen, and save their own bookmarks and progress. The book owner manages sharing, book details, analysis, OCR and recordings. Folders stay private to their owner. **Show shared books** lets each reader hide received books from their library view. Deselect a recipient or switch to **Only me** to revoke future server access. Copies already downloaded remain on their devices.

Preferences, bookmarks, AI answer caches, vocabulary exposure, reading time, read/currently-reading/set-aside status and browser/KOReader progress are separate for every reader, including when they read the same shared book. On the sign-in page, **Remember me** keeps a session for up to 30 days on that device; it is off by default. Unchecked sign-ins use a browser-session cookie with a 24-hour server limit. Browser session restoration can retain session cookies, so use **Settings → Account → Sign out** before handing a device to another user. Signing out or switching users clears the active account and local preferences while keeping that account’s downloaded books and pending offline work by default. The confirmation includes an unchecked **Remove this account’s downloaded books from this device** option. Selecting it removes only that account’s downloads and download queue; the server library stays saved. Retained downloads are available again after that same account signs in and are never shown as another account’s downloads. Administrators may disable remembered logins or change their duration, the session-only duration, maximum browser sessions, account expiry and OPDS/KOReader device access. **Revoke browser sessions** signs that account out without deleting books; reset its password to revoke saved device credentials too. Remembered sessions survive server restarts, use an HttpOnly cookie rather than a saved browser password, and can still be revoked by logout, password changes, resets or account disabling. A password change retains the current device's remembered/session-only choice. OPDS and older clients can continue using HTTP Basic authentication with each user's own credentials. Use HTTPS for remote access.

Users initially use the server's AI connection. They can save a separate model/API key in **Settings → AI connection**, or choose **Use server AI connection** to return to the default. Members can use the server-approved endpoint or OpenAI, OpenRouter and Groq; administrators can configure other endpoints. A member's API key and connection changes never change the administrator's connection. The shared Kokoro connection and Anna’s Archive mirror/retry policies are administrator-managed. Readers may save their own private Anna’s Archive membership key in **Settings → Book sources**. A new reader does not inherit the administrator’s membership key; grant **Allow use of the administrator’s Anna’s Archive membership key** in their account permissions to offer that option. Each queued import rechecks its owner’s current permission before using the shared key. The existing Audiobookshelf connector remains exclusive to the initial instance owner, including automatic exports and listening-position sync, so another reader's private books or progress are not sent through that account.

Keep `.env` unchanged after changing an administrator password in the app: the in-app password survives normal restarts. Explicitly changing the initial `READER_USER` or `READER_PASSWORD` in `.env` is an administrator recovery path and revokes that account's old sessions. Back up the entire data directory, including `accounts.sqlite`, and keep credentials outside Git. Removing `READER_PASSWORD` after accounts have been created does not reopen anonymous access. An installation that has never configured accounts can still run in the existing trusted-LAN, passwordless mode.

## Reading controls

The browser and Android app show a loading screen until the signed-in library and initial view are ready. It reports the current stage, elapsed time and saved-book counts during offline cache loading. Failed startup offers **Try again**. Background **Process queue** entries show section/passage counts during narration and vocabulary analysis, repair-window counts, download progress, current stages and elapsed time where available. Updated PaddleOCR services report live pages processed; older services and built-in OCR remain usable with a stage indicator when no percentage is available. Server status checks are distinct from worker progress, and a completed page/section counter does not mean that final file saving has finished. Rebuild `reader` for the shared app/browser interface and `paddle-ocr` for live OCR page counts; existing APKs load the updated interface from the server.

**Settings** opens a separate page. Use **Back** to return to the library or your saved reading position. Reader page numbers are buttons: select one, or open **Sections → Jump to page**, to enter a page. PDFs use document pages; EPUBs use pages within the selected source section and depend on text size. On phones and tablets the reading surface fills the available width. The audio toolbar’s **×** hides its controls while playback continues. Tap outside **Book sections** to dismiss it.

The default **Quiet library** keeps statistics in **Reading history** and book tools under **Book options**. **Show reading details** expands book statistics and tools. Filters remain available in both views. Search, format, level, sort and status use one compact row. Choose **All formats**, **EPUB** or **PDF** to filter the library; on mobile, open **Filters**. This format preference follows your account across sessions and devices and combines with search, categories, reading status and shared-book visibility. Star a book to mark it **Currently reading** and keep it first, including when sorting by vocabulary density. Unstar it to remove the pin. **Set aside** saves a separate status and removes the book from the default **On shelf** view; choose **Set aside** or **All books** to find it, then **Return to shelf** when desired. Neither action changes completion, text, audio or bookmarks. Starring a set-aside book returns it to the shelf. These choices persist across browsers; demo visitors have separate temporary choices.

The reader’s **Immersion mode** button, also available in Appearance settings, hides page numbers and reading progress. The Process queue button slides off the left edge and returns when you exit Immersion mode. The audio toolbar shows elapsed and total listening time and the recording’s completion percentage whenever it’s open. Listening time reflects the playback speed. Word help and summaries remain available, and reading activity is tracked in the background.

**Interface language** is separate from book, summary and translation languages. Choose English, Spanish, Portuguese or Mandarin; technical help and server errors can fall back to English. **Native language (L1)** is optional. Setting English, for example, excludes English from book vocabulary breakdowns, the seen/likely-known catalogue, below-threshold lists and vocabulary-overlap recommendations. Actual reading records are retained, so changing or clearing L1 updates these views without rescanning books or losing exposure history. Literal book word counts and reading-time totals remain available for every language.

**Reading history** shows total active reading time and a per-language breakdown. Time pauses after **two minutes without interaction**, while the app is hidden/unfocused, or while a dialog is open. Page turns, keyboard/touch actions, scrolling and intentional word lookups renew activity; automatic audio page turns and passive mouse movement do not. Long sleep/timer gaps are excluded, retries are idempotent, and overlapping intervals from multiple tabs/devices count once. Mixed-language time is an estimate based on visible text, not a measurement of eye movements. Server totals persist across sessions and book deletion; offline intervals sync on reconnection.

Select the reader’s **search** button for whole-book phrase search and a **character guide**. A search result jumps to its text position and updates normal page/audio following; the previous-location button returns to where you were. Search ignores case and accents, including Spanish/Portuguese diacritics, and supports Mandarin. Character explanations use only excerpts reached by your current page. The summary panel also has an **Ask the chatbot** box with **Current page** and **Book so far** scopes. Answers use your summary language and configured model. Earlier context is selected within a bounded budget; later text is excluded before prompting. The model may still misinterpret or invent details, so these tools do not guarantee spoiler-free or error-free answers.

## About, setup and saved AI answers

**About** explains the project's purpose, an anonymous personal story, access and equity commitments, and the research informing its reading experience. Links lead to primary work by Krashen, Mason and Smith, VanPatten, Nakamura and Csikszentmihalyi, Kohn, Ryan and Deci, and extensive-reading research. The page distinguishes these foundations from claims about Langy's own effectiveness. **How to** covers Docker setup, local models, external OpenAI-compatible providers, API keys, costs/privacy, narration, offline reading and maintenance. Both pages are available on self-hosted installations and the demo.

**Settings → Language help → Save and reuse AI answers** is enabled by default and follows the reader account. Completed summaries, deeper explanations, word help, book questions, character guides, reading estimates and discovery generations are cached persistently in `ai-responses.sqlite` in the data directory. Matching requests reuse answers across sessions and devices. Keys include the model/endpoint configuration, action and complete request context; changing those inputs produces a new answer. Only hashed request keys and completed results are stored in this cache. Concurrent identical requests share a generation; failed or aborted requests are retryable. Demo accounts have separate caches that expire with their sessions.

Turning saving off clears that account's saved-answer cache and bypasses new cache reads/writes. **Clear saved AI answers** forces subsequent generation to request a new answer. Already-rendered text and library artifacts such as completed analysis and discovery results remain visible. Back up the data directory to preserve saved answers. Provider-side prompt caching is separate; new requests can still incur provider charges.

On touch devices the library uses a collection selector, compact filters, cover cards, a book action sheet and bottom navigation. Book options contains actions only. Reading statistics appear separately when **Show reading details** is enabled. Desktop retains its sidebar and full library controls.

## Offline reading and Android

Choose **Book options → Save offline**, select whether to include a synced recording, then **Add to download queue**. The dialog closes immediately so you can keep reading or queue other books. Open **Process queue** in the library or mobile bottom navigation to see each book’s status, progress bar and transferred bytes, cancel a queued/active transfer, or retry a failed download. Completed tasks clear automatically from Process queue, including book downloads; failed tasks remain for retry or dismissal. Clearing a task never removes a downloaded book. Books download one at a time. The device saves the queue and resumes interrupted jobs after reopening or reconnecting; interrupted transfers restart safely. Keep Langy open while downloads run—Android may suspend a WebView after the app is backgrounded. Byte counts measure the current book/audio file; the bar also includes dictionary and reader preparation.

Langy saves the EPUB/PDF, indexed text, available dictionary entries, bookmarks, the reader’s fonts/PDF resources and optional complete audio. Completed packs show **Downloaded** on the library card. Wait for the download to finish before disconnecting. Downloaded source files open from device storage immediately, including while online. A failed, cancelled or interrupted replacement keeps the previous completed pack. Remove a pack using the same dialog.

Offline reading supports page navigation, saved dictionary help, Mandarin pinyin, whole-book search and downloaded audio with synchronized page following. Dictionary coverage varies by language and the installed datasets; offline meaning lookup does not call an AI API. New AI answers, audio generation, PDF OCR and external imports require the server. Browser storage limits apply, especially to long audiobooks; download without audio or remove another pack if space is insufficient. Packs with over 150,000 dictionary candidates need smaller volumes.

Bookmarks, completion/currently-reading/set-aside changes, reader preferences, reading positions, time and vocabulary exposure remain on the device when offline. Reconnection retries pending changes, including positions from books you have closed. A newer position on another device is retained until you choose how to resolve it. Offline packs, bookmark outboxes and download queues remain tied to their account. Switching accounts retains them by default and loads only the new account’s data. Choose the removal checkbox during sign-out or switching to delete the current account’s downloads. Keep these downloads on your personal device.

The Android app is built by [Build Android APK](https://github.com/Attach7830/Langy-Reader/actions/workflows/android.yml). Download and extract **Langy-Reader-Android** from the latest successful run’s Artifacts, then install `app-debug.apk` (Android 8+). In **Settings → Devices → Android app → Server connection**, enter your public HTTPS Langy URL and the same username/password used in your browser. For example, use `https://books.example.org`; do not enter your Audiobookshelf URL. The app stores its remembered login encrypted with Android Keystore and keeps external links in your browser. Update your server before downloading reading packs. Its initial connection and each new pack need Internet/server access; downloaded packs remain usable without it. Browser offline packs likewise need HTTPS or localhost.

From version 1.2, the Android title/action bar is absent in every view, including outside full screen. Server connection and Reload app remain in **Settings → Devices → Android app**. Main-frame connection failures reopen the connection dialog automatically.

This is a sideloadable preview, not a Play Store release. Version 1.1 uses the **Langy Reader Preview** app (`win.srtw.langy.preview2`), which installs alongside the original preview: that earlier build failed to retain its signing key and cannot receive a compatible update. Keep the old app until its pending reading changes have synced; sign into the same server in the new app and download offline packs there. The old app’s offline files are not deleted or transferred automatically.

The build now signs with an explicit, cached key, verifies its public certificate against `android/preview-signing.sha256`, and fails rather than silently replacing a missing signing identity. The owner’s private backup can restore the key through the repository secret `LANGY_ANDROID_KEYSTORE_BASE64` if its cache is lost. The canonical repository also uploads an encrypted key backup readable only with the owner’s separately retained private backup key. Neither private key nor plaintext keystore is committed or uploaded as a public artifact. Forks generate their own identity and do not use the canonical backup recipient. Production distribution still needs a managed release key. The APK has been compiled in CI; physical-device behavior should be checked on your Android/WebView version.

## Audiobookshelf

Open **Settings → Devices → Audiobookshelf**, enter its full server URL and API key, and select **Save Audiobookshelf**. Separate machines are supported: for example, Langy can connect to `http://192.168.1.20:13378` if that is your configured ABS address. Under **Category destinations**, link each Langy folder to an ABS library and folder, including **Uncategorized**. You can also edit a Langy folder and choose its **Audiobookshelf library** and **Folder** directly. Every automatic or manual export follows that book’s current folder link. An unmapped folder waits; it never falls back to the old global/default English folder. For an unmapped book only, you may explicitly select a one-time destination in its book tools. Pending exports recheck the book’s current folder and mapping after edits and server restarts. The separate import-library selector does not change export routing. The link applies to existing and future books, including already completed audiobooks. If a previous Langy export is in another ABS folder, Langy exports a fresh copy into the assigned folder and links progress to that copy; it never deletes, moves or overwrites the old ABS files. Duplicate-title checking is scoped to the assigned folder, so a same-named book in an unrelated language folder cannot redirect the transfer. Matching audio in the assigned folder still requires approval before replacing local Langy audio. Automatic export can be disabled. ABS folders must already exist in their library configuration. The API key stays in a private file on the Langy server; its ABS account needs upload/download permissions.

**Automatically link progress when title and author match** is on by default and works in both the web reader and Android app, including existing books. Opening a book checks accessible ABS libraries and all catalog pages. A linked Langy folder narrows the search to its assigned ABS folder; without a mapping, the title and author must identify exactly one item. Case, punctuation and repeated whitespace are normalized, but missing authors, different titles/authors and ambiguous editions are never guessed. Links survive restarts and metadata/folder changes are rechecked. The instance owner’s ABS account is never used for another user’s private books. This switch is independent of automatic export.

Imported/exported identical recordings keep timestamp synchronization. Metadata matches with other recordings, or books without local narration, sync by approximate book percentage. Reading-only EPUB/PDF books can resume near ABS’s listening position; different editions or abridgments can have different content at the same percentage. Ebook-only items exchange `ebookProgress`; ABS’s own ebook reader may require an edition-specific saved location to resume an exact page. Existing different positions are offered for review rather than silently overwritten. Auto-linking transfers progress only and never replaces audio or book files.

**Automatically export ready audiobooks** is on by default. Once connected with an explicit category destination, Langy queues completed generated narration and synced uploaded/imported recordings in the background, including existing ready recordings after connecting or restarting. It checks every accessible ABS book library, across all catalog pages, for a matching title before uploading. Matching ignores case, punctuation and repeated whitespace; accents and different words remain distinct. When a matching title has audio, Langy proposes importing that audio instead. If Langy already has a recording, **Process queue** asks whether to replace it. Approval downloads and aligns the Audiobookshelf recording first, then deletes only the local recording named by that proposal. Declining or a failed download/alignment keeps the local recording. Other Langy recordings are retained. These decisions survive restarts. Titles without importable audio block duplicate exports. Successful uploads are remembered while ABS indexes its files, and interrupted uploads are held for review rather than blindly repeated. Connection/catalog failures retry automatically with a delay. **Check ABS upload** in Process queue verifies an interrupted upload by its exact unique filename and links it when found, without uploading another copy. Turn automatic export off in Settings → Devices → Audiobookshelf to use manual exports instead.

Under a book’s **Analysis & audio → Audiobookshelf**, export the selected complete MP3, EPUB/PDF, embedded cover when present, and metadata/chapters. Every export uses a fresh, uniquely named directory to avoid overwriting existing Audiobookshelf audio, book, cover or metadata files. The metadata keeps the real book title. Langy waits for ABS to index the files and automatically links the exact uploaded filename and matching duration; a similar title or duration alone does not identify a recording. It never deletes or replaces Audiobookshelf files. Alternatively select an existing ABS audiobook and **Import audio and sync with this book**. Replacing an existing Langy recording requires approval in **Process queue**. Its tracks are downloaded in order, assembled where necessary and automatically queued for alignment; the imported recording is linked to that ABS title. The usual 200-track, 1 GiB, 72-hour recording limits apply.

Transfers run in the background with a visible status. Playback positions use audio seconds from the linked recording, not book percentages. Langy’s alignment maps those seconds to the text. Selecting a different recording never reuses the old recording’s ABS link. If another device changes the ABS position, choose **Resume ABS position** or **Keep this position**; offline listening positions are retained for a later retry. Changing the ABS connection/key requires linking recordings for that connection again. Live compatibility still depends on your installed ABS version and permissions.

Book recommendations include **Search Anna’s Archive**, opening a search for the recommended title and author on your configured mirror. You choose the edition and import it normally. Single and bulk Anna’s Archive downloads enter the background queue immediately. **Queue if unavailable** is enabled by default, retrying transient failures every six hours; individual requests can opt out, and the global Book sources setting can disable retries. Invalid credentials are not retried automatically. Free slow-download browser checks still require user interaction.

Open **Settings → Language → My reading languages** to save the languages you read. Import book and bulk downloads suggest only that list for primary/additional languages, while blank fields still use automatic detection and other valid language codes remain accepted. The list follows your reader account across browsers. Portuguese (`pt`, `pt-BR`, `pt-PT`) is supported by analysis, hover requests, language-aware narration and PDF OCR (`por`).

Open **Bookmarks** in the reader toolbar, or press **M** (customizable), to save the current EPUB/PDF position with a label and optional note. Saved bookmarks follow your library across browsers; opening one uses the same page/audio navigation and allows returning with the previous-location control. Repeatedly saving the same source position updates its note instead of adding duplicates. Demo bookmarks are private to each visitor.

Select text and choose the bookmark icon or press **K** to save that passage. Type a note if you want one, then press **Enter** to save. **Shift+Enter** adds a line break in a note.

**Import book** and **Book details** include six selectable default covers: Terracotta, Forest, Ocean, Night sky, Parchment and Plum geometry. Previews show your title and author. The choice is saved with the book across browsers. **Original / automatic** restores the embedded image when available, or the existing generated cover; choosing a design never alters the EPUB/PDF or deletes the original cover.

EPUB counts are extracted locally before lemma analysis and recover automatically for existing books even if the language service is unavailable. PDF text extraction still needs the language service. Illustrations and image-only sections are skipped without changing chapter positions; text stored only in images needs OCR and contributes no selectable words.

**Total words read** at the top of the library estimates reading volume from displayed passages and books marked read. Saved page-view history is included automatically. Overlapping views and layout changes within a reading session count once; reopening a book starts a new session, so rereading counts again. Marking a book read fills only the source positions not already tracked, and marking it unread removes that inferred contribution while retaining tracked reading. Mandarin characters have their own total. Pending completed books contribute when text counting finishes; lemma analysis can finish separately. Counting runs locally without AI API calls, and totals refresh when you return to the library.

Each library card has **Mark as read**, which adds a saved **Read** badge. Select **Mark as unread** to undo it, and use the **All books / Unread / Read** filter to browse by completion. Status is stored on the server and persists across browsers and restarts; demo visitors have their own temporary status, including for the shared sample book. Marking read preserves the reading position and contributes the analyzed book's vocabulary as one complete reading, including books already marked read before this update. If analysis is pending, the contribution appears when it finishes. Marking unread removes the inferred completion contribution and keeps actual tracked reading.

In the category editor, enable **L1 Folder** for books you read without comprehension assistance. This hides summaries, tap/hover definitions, synonyms and translations, phrase explanations, character guides and pinyin for existing books and books imported or moved into that folder. Reading, whole-book search, bookmarks and audio stay available. Turning it off restores your saved assistance preferences. Each account controls its own folders; sharing a book does not turn assistance off for other readers. The choice is saved with the folder and applies to downloaded books using that saved metadata.

In the category editor, optionally choose a **Folder language**. Saving assigns it to books already in the folder; imports and books moved there also inherit it as their primary language. Books using automatic detection become restricted to the folder language, while explicitly selected additional languages are preserved for mixed-language books. Changing a book's language queues fresh analysis without replacing the book file, audio or bookmark. Clearing the folder language stops automatic assignment and keeps the books' current language settings.

## Connect an OPDS reader

Your self-hosted installation publishes an [OPDS 1.2](https://specs.opds.io/opds-1.2.html) catalog at **`http://YOUR_SERVER_IP:8088/opds`**. Open **Settings → Devices** to copy the address for your current installation. No extra container or model is needed.

On Xteink with [CrossPoint firmware](https://github.com/crosspoint-reader/crosspoint-reader/blob/develop/USER_GUIDE.md), open **Settings → Connectivity → OPDS Servers → Add Server**:

- Server name: `Langy`.
- Server URL: `http://YOUR_SERVER_IP:8088/opds`, or your installation's HTTPS hostname followed by `/opds`.
- Username/password: your own Langy account credentials when sign-in is enabled (the initial administrator uses the credentials configured in `.env` until changed). CrossPoint supports HTTP Basic authentication; it cannot complete an interactive Cloudflare Access login.

Browse **All EPUB books**, **Recently added**, or **Categories**, or search by title/author. Feeds contain at most 20 entries per page for small readers. Downloads keep the original EPUB and its table of contents. The separate **PDF books** catalog serves original PDFs for compatible readers; Langy does not convert them for Xteink. Other OPDS clients can also use `/opds/books?format=all`.

The Xteink must be able to reach that server address over Wi-Fi. `localhost` refers to the device itself. Use HTTPS for connections outside your trusted home network. The catalog, search, covers and downloads all use the same Langy sign-in; passwords are not included in catalog URLs. OPDS is disabled in demo mode to keep visitors' uploads private.

OPDS supplies books to the device. Its firmware handles reading and dictionary lookup; Langy's AI summaries and audio synchronization remain in the browser. Reading position uses the separate sync connection below. Actual Xteink hardware has not been tested.

Opening a book resumes its shared position automatically when this browser has no unsynced changes. An update arriving while you read, or a conflict with offline reading, offers **Resume there** and **Keep this position**. The browser uses version checks to avoid silently overwriting another device's newer position. Native KOSync clients use the protocol's last-write-wins behavior; sync before switching readers. Moving backward intentionally is supported.

PDFs share fixed page positions with compatible readers. The sync button retries an unavailable connection; local browser progress remains saved offline. You can disable syncing for a browser in **Settings → Devices**. This transfers reading position only, not bookmarks, annotations, vocabulary, or audio time.

Device connections require a password. Other readers always use their own Langy username and password, with separate progress for the same document. Browser-to-browser sync also works on a trusted LAN installation without a password, but native device authentication stays disabled until a password is configured. The sync password or its derived key is never sent to the browser settings API. Progress is stored in `progress.sqlite` in Langy's data volume; include the volume in backups. The public demo disables shared progress sync entirely.

Protocol requests, position mapping, browser conflicts, and offline recovery have automated coverage. Physical CrossPoint/KOReader devices still need an end-to-end check after deployment.

## Available storage

The library shows the current account’s saved media usage and remaining allowance, constrained by the free space on the server’s data drive. Administrators set a **Saved library limit (GiB)** when creating or editing an account; blank means unlimited and zero blocks additional saved media. Owned EPUB/PDF files, original OCR backups, cover images, generated/uploaded/chapter audio, transcripts and imported fonts count toward the allowance. Shared database records, service models and temporary processing space are separate. Shared books count toward their owner’s allowance. An administrator lowering a quota does not delete existing files or prevent reading them. Concurrent imports reserve their space so they cannot independently exceed the same quota. Failed imports clean up partial files. Replacing a cover or OCR output conservatively requires enough room to save the new file while preserving the previous one.

The meter updates when the library refreshes and every minute while visible. **Refresh** checks immediately. Accounts with a limit see their saved library allowance. Unlimited accounts see the data drive’s actual capacity bar, including space occupied by other files or reserved by the filesystem, with their own saved library usage below it. If the server cannot report drive capacity, the saved library usage remains visible with an unavailable message. This is server storage, separate from a reader device’s SD card.

Demo visitors see only their personal upload allowance (four books, 20 MiB each); the demo does not expose the server's disk capacity. The shared demo storage cap still applies independently.

## Move an existing library to another drive

Prepare and mount the destination drive first, with a persistent mount configured in `/etc/fstab`. The migration helper does not format disks. For example, with your data drive already mounted at `/srv/langy`, run from the repository:

```bash
git pull --ff-only
sudo bash scripts/migrate-storage.sh /srv/langy --tunnel
```

Omit `--tunnel` if you do not use `compose.tunnel.yaml`. The helper requires a running personal reader using a named Docker volume and an existing `.env`. It refuses an unmounted destination or a nonempty destination `library` folder. It builds the reader and verifies its copy tools can run before downtime, stops it to copy all books, recordings, settings and SQLite databases, and compares every copied file before switching. The copy uses the reader's named image without downloading a helper image. Keep this terminal open until it completes.

The helper preserves permissions, retains the original volume and a private `.env.storage-before-*` backup, and sets `READER_DATA_SOURCE` and `READER_STORAGE_ID` in `.env`. Existing credentials, including literal dollar signs, are retained. The reader validates the destination's `.langy-storage-id` before opening any databases; an absent drive or wrong folder causes startup to fail instead of initializing a new library. A failed copy or startup restores the old settings and attempts to restart the original volume. Copies left by an incomplete migration require inspection before retrying.

Your usual Compose commands, including the tunnel override, continue to use the configured host folder through `.env`; no separate storage override is needed. Refresh the library's storage meter and verify books, recordings and reading progress after migration. The original volume remains a backup on the previous filesystem, so it continues using that disk's space until you choose to remove it. Do not remove it until the migrated installation has been checked. New installations can keep using the default named volume without these optional settings.

## Lemmas and reading demand

Books are analyzed automatically after import, including books already in the library when the updated app first opens. **Analysis & audio** shows whole-book and per-section vocabulary counts. Spanish, English and Portuguese use contextual spaCy models; other supported languages use lookup tables. Hover help also shows a detected lemma. If lemmatization is unavailable, the app labels its counts as word forms. Detected proper names are excluded from lemma totals.

Spanish future subjunctives such as **hubiere → haber**, **tuviere → tener** and **hiciere → hacer** use attested conjugation paradigms from the installed lookup dictionary, including compound forms such as *hubieres terminado*. Context preserves nouns such as *cantares* and *pesares*. Ambiguous forms show **Possible lemmas** on hover; an unresolved form contributes one provisional lemma, rather than counting every candidate. Existing Spanish and mixed-language books are queued for fresh analysis once after this update, and saved reading exposures are reindexed when it finishes. Book files, bookmarks and audio do not need to be replaced. See [the targeted validation](benchmarks/lemmas/SPANISH-FUTURE.md) for measured results and limits.

Spanish vocabulary normalization also separates attached pronouns: **achicarme / achicándome → achicar + yo**, **agregarlo → agregar + él**, and **aproximarse / aproximársele → aproximar**, with each pronoun tracked at its own source position. Combined model outputs such as “achicar yo” are no longer inventory entries. Attested preterites share their infinitive, including **oyó / oyeron → oír**. Adjective gender/number variants and dictionary-attested noun pairs such as **adulto / adulta / adultos / adultas** share a base word. Participles identified as verbal participles, including **almizclado / almizclada**, contribute to **almizclar**; lexical nouns such as *vestido*, *bolsa* and *música* retain their noun reading. This learner grouping can differ from strict dictionary/UD lemma conventions. Existing Spanish analyses and exposure histories refresh once after upgrade, without changing source words, audio timing or book files. See [the normalization checks](benchmarks/lemmas/SPANISH-FORMS.md) for scope and remaining errors.

Spanish now uses a local dictionary with **668,422 tagged grammatical readings** from [FreeLing's Spanish Resource Grammar data](https://github.com/TALP-UPC/FreeLing/tree/0bae6b7f6d1b405e67658895de54b59bfb3b6338/data/es/dictionary/entries), alongside contextual spaCy analysis. Noun/adjective paradigms and imperative forms come from those grammatical records, covering pairs such as **profesoras → profesor**, **escritoras → escritor**, **investigadoras → investigador** and **leonas → león**. The same clitic grammar applies to any supported verb, including up to three attached pronouns, accent restoration and imperative letter changes. Distinct nouns such as *manzano/manzana* stay separate. Ambiguous readings retain their alternatives on hover. Unknown entries use a conservative lookup fallback; contextual tagging can still be wrong.

The Docker build downloads checksum-pinned dictionary sources and builds the local index. Runtime analysis requires no download, LLM or paid API. The original lexical sources, LGPL-LR license and attribution accompany the derived index in `/opt/models/spanish-morphology/`. Existing Spanish books and exposure histories refresh once after this dictionary upgrade. See [the generalized-rule validation](benchmarks/lemmas/SPANISH-GENERALIZATION.md) for reproducible checks and benchmark limitations.

Mandarin uses **unique Han characters**, with a separate count of character occurrences. English, Portuguese and other languages keep their own lemma/word-form counts. The library and analysis table show separate language totals for mixed books; Mandarin characters are never added to a lemma total. Punctuation, English letters and pinyin annotations are excluded from Han counts. Simplified and traditional variants are distinct written characters. The Mandarin reading estimate receives the character inventory and character coverage within the book, together with sampled passages; it considers character familiarity, compound-word meanings and sentence demands. There are no fixed character-to-ACTFL/HSK score cutoffs.

Langy estimates the reading demand from passages sampled across the book with the configured language model. Its rubric follows the broad Novice, Intermediate, Advanced, Superior and Distinguished ranges in the ACTFL reading guidelines. It considers discourse, syntax, context, vocabulary and inference. The book panel shows a rationale, sample count and quotations verified against the sampled text. The library can filter by the estimated reading range. These provisional text estimates have not been calibrated against formal proficiency assessments. [ACTFL proficiency guidelines](https://www.actfl.org/proficiency-guidelines-overview)

Reading-demand estimation has its own queue, so narration, audiobook synchronization and rescans do not hold it up. Only one automatic estimate runs at a time. The analysis panel distinguishes queued and running requests, shows elapsed time and errors, and offers **Retry reading estimate** (or **Restart reading estimate** while pending) without repeating vocabulary analysis. A request has a hard 100-second deadline in addition to the AI connection's request timeout. Interrupted requests resume after a restart; missing estimates for analyzed books are queued automatically. An unavailable or slow model is reported as an error instead of leaving the estimate pending indefinitely.

The OPI assesses a person's speaking. Langy's reading estimate describes text demand. A reader's proficiency requires performance assessment. [ACTFL OPI](https://www.actfl.org/assessments/postsecondary-assessments/opi)

## Seen vocabulary and recommendations

Langy records vocabulary from the text visible on a page after it remains displayed briefly, independently of whether audio is enabled. Inflected words use the analyzed lemma; proper names are excluded in line with book analysis. Mandarin uses individual Han characters, and each other language keeps its own lemma or word-form inventory. **Vocabulary** in the library opens the saved catalogue, with language/search filters and dates. Records are shared by browsers using the personal installation; demo visitors keep separate, expiring catalogues. Previous reading and KOReader progress do not automatically mark vocabulary as seen. A bounded browser queue retries temporarily failed saves.

Vocabulary analysis treats a bound **anti-** prefix as part of its word, including joined and hyphenated forms. It does not add a separate `anti` lemma for `antihéroes` / `anti-héroes`; independently written `anti` and unrelated words such as `antiguo` retain their ordinary analysis. Tokens containing numerals, including Unicode digits and split forms such as `U2`, `4x4` and `COVID-19`, are excluded from lemma inventories. These filters do not remove text or reduce the independent surface word/read counts. Existing analyses refresh once after upgrading; saved reading ranges are retained and their vocabulary contributions are rebuilt.

**Vocabulary → Exposures before likely known** sets a threshold from 1 to 10,000, initially 20. The catalogue shows each item's exposure count and whether it reaches the threshold, with separate likely-known totals for every language and Mandarin characters. The library can sort by **Lowest below-threshold vocabulary density**, and book analysis shows likely-known counts alongside seen and not-yet-seen vocabulary. This estimate uses tracked reading plus inferred exposures from books marked read; the catalogue separates those sources. The default is an adjustable heuristic, not a validated mastery cutoff. Changing the threshold recalculates the estimate immediately and keeps the reading history.

A read mark counts each analyzed lemma or character occurrence in a book once, adding only source positions not already encountered in tracked reading. A partially read book therefore fills its remaining gaps; a fully tracked first pass is not counted again. Additional tracked rereading sessions are retained. Repeated read marks and reanalysis do not inflate the tally. Marking unread removes the inferred contribution alone. The read mark is evidence supplied by you, not proof of attention, comprehension or mastery; saved progress and KOReader positions alone do not create it.

Each occurrence of a lemma or character counts once per reading session. Inflected forms contribute to the same lemma; overlapping pages, retries and font/layout changes do not count the same occurrence again. Reopening a book to reread it starts a new session. Earlier saved reading ranges are reused conservatively as a single legacy session per book because previous versions did not distinguish rereading sessions. Language corrections rebuild the occurrence catalogue from those saved ranges.

Library cards and **Analysis & audio** show how many unique items are **Not yet seen**, separately for each language. This is an exposure estimate, not proof that a word is unknown or mastered. **Lowest unfamiliar vocabulary density** sorts by `distinct unseen lemmas ÷ surface word count × 1,000`, lowest first. **Lowest below-threshold vocabulary density** uses distinct lemmas below your saved exposure threshold in the numerator. Book cards show the raw count and rate; for example, 300 unseen lemmas in 100,000 words is 3 per 1,000, ranking ahead of 100 in 10,000 words (10 per 1,000). The denominator includes repeated words, names and numbers, matching the book's word count. The numerator counts each unfamiliar lemma once regardless of its frequency; the rate is not a percentage of unknown word occurrences or a proficiency score.

Mandarin uses distinct unfamiliar Han characters per 1,000 Han-character occurrences. Mixed books calculate a separate rate for each language and use the mean of those rates for sorting, without adding lemma counts to character counts or letting familiar text in one language dilute another language's rate. Missing or zero-length text has no rate and sorts after measured books; a genuine rate of zero sorts first. Existing books gain these rates from their saved text automatically without reuploading or AI requests. When a book's language selection changes, its saved reading ranges are reanalyzed to correct the catalogue as well as its book statistics.

Select **Find books with similar vocabulary** in a book's analysis panel to see other analyzed books from your library, ranked by the average per-language Jaccard overlap of their vocabulary inventories, then by lower unfamiliar vocabulary density when similarity ties. Matches show shared vocabulary and the candidate's not-yet-seen counts and rates. Mandarin character overlap is compared separately from lemma overlap. Recommendation calculation is local, needs no AI call, and does not infer similarity of plot or genre.

### Discover books beyond your library

Open **Discover** in the header or **Discover books** in the library sidebar. Choose a book language (blank uses the most common primary language in your library), optionally describe what you want to read, and select **Find recommendations**. The model configured under **Settings → AI connection** examines library titles, authors, categories and read status, plans web searches, then selects up to six books from verified catalogue records. Each recommendation includes a brief connection to specific library books and source links. Bundled Ollama and your own local Ollama/OpenAI-compatible server are supported; no separate paid model or search API is required. A paid provider selected in AI connection retains that provider's normal billing.

Discovery uses a bundled, private [SearXNG](https://docs.searxng.org/admin/installation-docker.html) search service and the [Open Library Search API](https://openlibrary.org/dev/docs/api/search) for title/author records. Model-proposed titles are search leads until verified; the model can select only returned catalogue IDs. Books already in the library, duplicate titles, unsupported languages and unsafe source URLs are filtered out. Imported recommendations disappear from saved results. This verifies catalogue identity, not every literary interpretation; the explanation remains an AI suggestion. External books do not get estimated vocabulary overlap or reading difficulty until imported and analyzed.

The initial `docker compose up -d --build` starts search too. To add it to an existing installation without rebuilding language or Ollama:

```bash
docker compose --env-file .env -f compose.yaml -f compose.tunnel.yaml \
  up -d --build --no-deps search reader
```

Omit `-f compose.tunnel.yaml` if you do not use the repository's tunnel stack. Search exposes no host port and needs no public hostname. Its configuration and cache use `search_config` and `search_cache` volumes; the upstream startup script creates a random secret from the configuration template on first launch. To reuse an existing SearXNG instance, set `READER_SEARCH_URL` in `.env` to its base URL and enable its JSON search format. If general search fails, the app explicitly labels catalogue-only recommendations; if no candidate can be verified, it displays an error rather than unverified titles.

Discovery runs on request in a background queue with cancellation, time limits and explicit progress. Results persist across restarts, are reused for matching requests for up to 24 hours, and are marked stale when the library or selected model changes. Larger libraries are fully counted and sampled for bounded AI context. Search queries use titles, authors, language names and literary topics; full book text and vocabulary records are not sent to the web search services. Internet access is required for search and catalogue lookup. Demo results are scoped to each visitor and expire with that visitor. Open Library requests are cached, serialized and spaced to respect its default request limit.

Open **Analysis & audio → Words below threshold** for a searchable, language-filtered list of that book's lemmas or Mandarin characters with fewer exposures than your saved likely-known threshold. Items are sorted by the fewest recorded exposures first; ties prioritize items occurring more often in that book. Each row shows its exposure count, frequency in the book, and an expandable example from the original text. Opening the list does not record reading exposures. Zero means no recorded encounters, not proven unfamiliarity; read-book contributions are included and the same written item in different languages stays separate.

The **Meanings** selector offers **English translation**, **Spanish synonyms / equivalents**, or **Spanish definition**. Meanings load progressively for ten items per page using the configured AI connection and the book's example passage. Spanish synonyms come from local dictionaries and are labelled as possible senses; when no synonyms are available, a labelled Spanish definition is generated instead. Other languages receive Spanish equivalents in synonyms mode. Generated meanings are labelled as AI output and do not alter lemma analysis or exposure counts. Successful meanings are cached with the book analysis, example passage, output mode and AI connection; changes to those inputs invalidate them. Errors can be retried per row. Demo AI rate limits apply, and every demo visitor has their own vocabulary threshold and exposure history.

## Mixed-language books, Mandarin and Portuguese

Books are monolingual by default, using their automatically detected or manually chosen primary language even when EPUB tags suggest other languages. In **Book details** (the pencil on a library card), enable **Multiple languages in this book**, add each language, and save. For a Mandarin–English book, select Chinese/Mandarin and English. Analysis, hover help, pinyin and narration are restricted to that selection, including when EPUB tags disagree. Excluding the primary language makes the first selection primary. Saving automatically queues fresh analysis of the existing file and removes stale totals while it runs; no reupload is needed. An empty extra-language field never requires another selection: Enter can save the book, and with no selections the primary language is used automatically. Turn this option off to return to the primary language only. The same choices are available during import. Existing unrestricted analyses are refreshed automatically; explicit multilingual selections are preserved.

When multiple languages are enabled, Langy uses EPUB `lang` / `xml:lang` tags and script/passage detection for word help, vocabulary analysis and narration. Mandarin, English and Portuguese passages can coexist in a book without sharing a vocabulary counter. Automatic identification of short, untagged passages can be ambiguous; correct language tags and the primary **Book language** help. Portuguese analysis supports `pt`, `pt-BR` and `pt-PT`; inflected forms are mapped to lemmas and known contractions are included in the vocabulary analysis.

Hover or tap Chinese text to see **the whole word's meaning, tone-marked pinyin, and the meanings/readings of each character**. Compound meanings are displayed separately from character meanings: a compound need not mean the literal combination of its characters. Simplified and traditional headwords come from the bundled [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) dictionary, with [Unicode Unihan](https://www.unicode.org/reports/tr38/) readings and definitions for additional characters. [pinyin-pro](https://github.com/zh-lx/pinyin-pro) supplies phrase-aware pronunciation; dictionary readings correct recognized compounds and alternatives remain visible for ambiguous readings. Unknown meanings/readings are explicitly unavailable. The normal English gloss lookup is local and needs no LLM/API request. Other hover modes still use their configured dictionaries or AI connection.

Mandarin dictionary popups show **one card at a time**, beginning with the whole word’s first dictionary definition and pinyin. **Down / Up** move through the word and its characters in order, for example **有意思 → 有 → 意 → 思**. The **▾** selector jumps to a card; **More meanings** expands that card’s other definitions. The compound and all character sections are never stacked on screen together. Other languages use the compact selector to cycle dictionary senses. **Escape** closes the popup (or an open alternatives list first). Closing resets the next lookup to the whole-word card, including cached lookups. A late AI translation preserves the selected card and appears only on the whole-word card.

For Mandarin books, use **Pinyin** in the lower reader toolbar, or enable **Settings → Language → Show pinyin above Chinese text**, to keep pronunciation visible while reading. The toolbar and **Y** shortcut share this setting. Turn it off to remove Langy's inline pronunciation; the setting follows your reader account and does not disable hover pronunciation. Pinyin is drawn above the original text (alongside vertical text), without changing EPUB/PDF text nodes, source word offsets or saved progress paths. It updates after page turns, resizing and font changes. Reflowable EPUBs reserve additional line spacing; fixed PDFs need selectable text and retain their original layout. Publisher-provided ruby annotations retain their source formatting. Noto Sans SC/TC font fallbacks are bundled for Chinese; very rare glyphs still depend on font coverage.

Under **Settings → Narration**, **Match Kokoro voices to passage languages** switches voices as the language changes, while preserving one continuous book recording. Standard Kokoro presets include Mandarin `zf_xiaobei`, Portuguese `pf_dora`, and English `af_heart`; your server must provide the selected voices. Set per-language overrides to use other voices, including a European Portuguese voice supplied by your TTS server. Kokoro's Portuguese presets use Brazilian Portuguese. Custom voice IDs without a recognized Kokoro language prefix retain your chosen voice unless an override is provided. Narration stays disconnected in the demo.

Uploaded mixed-language recordings use multilingual speech recognition instead of forcing the primary language. Alignment can match simplified recognized speech to traditional source text while leaving the book itself unchanged. Existing mixed-language recordings can be synced again or rescanned; changing narration voices requires generating new audio. Recognition quality still depends on the model and the recording, and estimates remain labelled.

CC-CEDICT data is distributed under CC BY-SA 4.0, Unihan under the Unicode license, pinyin-pro under MIT, and Noto fonts under the SIL Open Font License. Source links and notices are included with the dictionary and font packages. Dictionary definitions are indexed separately from application code.

## Scan PDF books with OCR

PDFs successfully processed by OCR show **PDF · OCR** in the library and reader header, including earlier completed scans. Select **Scan PDF with OCR** on a PDF library card. Choose installed OCR languages matching **My reading languages**, the OCR mode, and optional orientation correction, then select **Update PDF**. Choose only languages actually present; recognition does not identify an unknown language automatically.

The default built-in engine is OCRmyPDF/Tesseract in the `language` service. Chinese scans use 400 DPI and a longer page timeout; other languages use 300 DPI. Rebuild `language` to install these upgraded models. **Replace existing OCR** replaces a detected hidden text layer while preserving visible digital text. **Only scan pages without text** retains existing text pages. ### Optional PaddleOCR PDF service

For a separate Chinese OCR engine, the repository supplies a CPU-based **Langy PaddleOCR PDF service**. It uses pinned PP-OCRv5 server models for simplified/traditional Chinese, pinyin, English and Japanese. It requires an AVX-capable Linux host with enough free memory for the server models and page images; a modern home server is preferable to a small board computer. The first build downloads and verifies model files from pinned official PaddlePaddle model repositories over HTTPS. Recognition uses those local files, with network connections disabled inside the recognition worker. No paid OCR API is required.

On the same host as Langy, start the additional service from the repository directory:

```sh
docker compose -f compose.yaml -f compose.ocr.yaml up -d --build paddle-ocr
```

Open **Settings → Devices → PDF OCR**, choose **PaddleOCR**, enter `http://paddle-ocr:8000`, and choose **Save and test OCR connection**. The reader reaches the service through the Compose network. Built-in OCR remains selectable; a failing external scan never silently switches engines or replaces the book.

To run OCR on another server, clone this repository there, copy `.env.example` to `.env`, and set `LANGY_OCR_BIND` to that server’s private LAN/VPN address. Set a long, private `LANGY_OCR_API_KEY`, then run:

```sh
docker compose -f compose.ocr.yaml up -d --build paddle-ocr
```

In Langy, enter `http://YOUR-OCR-SERVER:8093` and the same key. Keep this port on your trusted LAN/VPN; use an HTTPS reverse proxy when appropriate. Inside the reader container, `localhost` refers to the reader itself. This connector requires the supplied PDF gateway; a generic PaddleOCR JSON API, Ollama URL, or language/Whisper URL does not implement its searchable-PDF protocol. Only administrators can change the connection. Keys remain on the Langy server and are not exposed to other accounts; redirect responses never forward them to another endpoint.

PaddleOCR renders one page at a time for recognition and adds invisible, positioned Unicode text to the original PDF. Cropping, page orientation, images, bookmarks and metadata are retained. **Replace existing OCR** removes ordinary invisible OCR text before recognition. In **Replace existing OCR**, mixed pages are scanned even when they contain selectable page numbers or headings. Retained digital glyphs are masked only in the recognition image to avoid duplicate text; the saved visible PDF is unchanged. **Only scan pages without text** still skips pages with existing selectable text. The OCR dialog reports newly recognized characters and scanned/skipped page counts separately from the number of pages containing any text. Service logs show counts for each page without printing book text. Its orientation option corrects detected text-line orientation rather than rotating the visible page. The selected vertical option orders detected Chinese columns from right to left. Recognition quality still depends on scan quality and typography; inspect a representative result before scanning a large collection.

Both engines update the **same book entry**, preserving its ID, title, author, folder, cover, bookmarks and reading status. The selected OCR languages correct its language metadata where needed. The original upload stays as a server-side backup; the searchable PDF becomes the active file. Text analysis refreshes while existing recordings stay stored and can be synced again if text timing changes. Refresh saved offline packs to download the updated PDF. Up to ten documents can wait in the queue, with one scan processed at a time; jobs survive restarts. If the OCR service is still busy (for example after a reader restart or cancellation), waiting scans remain queued and retry sequentially. Failed scans can be retried from Process queue using the currently selected OCR connection. Input/output limits are 120 MiB, 2,000 pages and one hour per document. OCR is available on personal installations.

The reader waits up to 61 minutes for the OCR response, allowing the service's one-hour processing window plus transfer time. This includes waiting for response headers, which arrive only after the searchable PDF is ready; scans longer than five minutes keep their connection open. Connection failures log a diagnostic code in the reader service and expose `errorCode` in the OCR job status, without logging service keys or PDF text. Language/connection checks keep their separate 15-second limit and remain available during a scan. Cancelling stops the reader's transfer; the OCR worker may finish its current document before accepting another.

## Rescan missed audio words

Alignment recovery is automatic. After complete book generation or audiobook synchronization, Langy queues a fresh local recognition pass when word positions are missing, estimated or flagged for review. Existing compatible recordings are checked after upgrading too. Each pass keeps good anchors, processes bounded audio windows, and records its final alignment signature so it does not continually rescan its own results. This uses the local language service, without manual word/time anchors or paid APIs. Recognition cannot recover speech absent from the recording or guarantee exact timing; source and voice quality still matter.

Nearby gaps share bounded recognition clips rather than repeatedly recognizing the same surrounding speech. The worker caches one repair’s source and accepted matches, checks database revisions between clips, and retains conservative anchor and segment checks. Existing jobs keep completed checkpoints and batch only the remaining windows after upgrading. This reduces repeated file extraction, recognition and whole-book reads without generating new narration. Progress percentages describe completed repair windows, not timing accuracy; a 99% accuracy claim would require an independently verified timing benchmark.

Choose **Rescan missed words** beside a synced uploaded recording, chapter-file audiobook, iVoox import or completed generated narration. This uses the existing audio and the bundled local speech recognizer; it does not regenerate narration, contact Kokoro, or incur AI API fees. Langy extracts short clips around unconfirmed text spans and recognizes them again with a fresh decoding pass, including gaps across previously unmatched sections. Existing recognized word positions are preserved, and candidates must fit the neighbouring matches and recording boundaries. Recognition confidence and non-silent audio checks reject weak candidates; words are not forced onto omitted or different text.

The panel shows whether repair is queued or running, its queue position, completed passages, newly found matches and remaining unconfirmed words. A repair can yield between recognition windows when another ready task has higher priority. Running and queued repairs support **Raise priority**, **Top priority** and **Lowest priority**. Retry an existing failed repair after updating; its error and completed checkpoints are retained. Results are applied atomically when the pass completes. Playback remains available using its existing alignment while work is pending; retry resumes completed clip checkpoints after an error or restart. **Cancel rescan** discards the pending pass and keeps the current alignment. The active reader refreshes its timing cache without restarting the audio. The audio file and its embedded metadata stay unchanged; the player's timing and markers are refreshed. A rescan can still leave gaps, and retained recognition matches may themselves contain errors. Estimated positions continue to support page following and are never highlighted as recognized words. Rescanning is available on self-hosted installations.

## Generated narration and timing

The persistent queue reuses compatible recordings, then assembles the complete book. Internal processing runs in sections and resumes interrupted work after a restart. The final file is published only after every readable section finishes. Choose **Replace existing recordings** to regenerate, or **Cancel queued audio** to cancel the book job; an active internal section may finish and remain cached. Completed books have one **Download complete book MP3** link. Empty pages are skipped.

On a self-hosted instance, open a PDF's **Analysis & audio → Review PDF text**. Use **←** and **→** to turn pages when focus is outside an input field. Enter page numbers or ranges to skip front matter. Choose **Draw boxes** and drag around the passages on a page. You can draw up to 16 boxes per page and arrange them in reading order. **Extract boxes to editor** combines their text in that order. Image-only boxes use the configured OCR service and the book’s languages. Use **Run OCR on all boxes** to rescan an area whose existing text needs correction. You can also use **Use selected PDF text** or edit the transcription directly. **Save reviewed text** remembers the boxes and applies your edited text to vocabulary analysis and audiobook generation. The original PDF and its page numbers remain available, and pages with edited text use page-level audio sync.

**Remove Latin characters** strips Latin-script letters and their attached accents from the current page’s transcript. **Remove numerals** strips number symbols, including full-width and circled digits. Use **Undo** or **Redo** for typing, cleanup and extraction. The keyboard shortcuts are **Ctrl+Z** and **Ctrl+Shift+Z**, or **Cmd+Z** and **Cmd+Shift+Z** on a Mac. Each page keeps its own undo history until the editor closes.

After generation, open **Analysis & audio → Adjust PDF audio sync** for a PDF recording with at least two narrated pages. Select a page, listen and scrub to the first spoken words of that page, then choose **Set start at playhead**. The quarter-second buttons let you fine-tune the playhead. **Save page timing** applies the adjustments in Langy. **Restore original page starts** recovers the generated timings.

The demo defaults to disconnected audio preview (`READER_DEMO_AUDIO_PREVIEW=1`). The headphones button, narration settings and podcast layout remain visible, while generation is disabled and no Kokoro requests are made. Personal installations are unaffected. An owner explicitly enabling narration on another demo can set `READER_DEMO_AUDIO_PREVIEW=0` and configure that demo's Kokoro connection.

EPUB narration preserves heading and paragraph boundaries without modifying the original reading text or offsets. Standalone chapter counters are spoken as labels (for example `1` becomes `第1章` in Mandarin), titles are separate utterances, and explicit silence separates them from the body. Existing books recover this structural metadata automatically without reuploading. PDF text extraction cannot supply equivalent heading structure reliably.

Mandarin body chunks are limited to about 180 source characters and prefer sentence/clause boundaries and intact compound words. This bounds alignment work instead of recognizing 1,800 characters at once. Whole-book audio remains one downloadable file, and pauses are included in its timestamps and chapter markers. This narration version has a new cache signature: generate or retry book audio to adopt it; previous recordings remain available.

Word timestamps come from local speech recognition matched to the source words. Recognition retries low-coverage chunks as well as empty ones, including short headings that can be mistaken for silence. Complementary matches are merged only when they fit unchanged neighbouring timestamps. Mandarin prompts preserve natural text, matching handles simplified/traditional characters, and denser phrase anchors tolerate recognition errors in long recordings. Recognition confidence is retained for review. When words still cannot be matched, Langy estimates their positions between matched timestamps or the boundaries of the generated audio chunk. Page following stays active, approximate sections are labelled, and estimated words are never shown as synchronized highlights. These estimates cannot guarantee exact page or word timing. Numeric headings are included; decorative sections without letters or numbers are skipped. Joining decoded audio by its sample count prevents encoder padding from accumulating into chapter timing drift. Playback speed can be changed independently of generation speed. Kokoro and voice support determine narration languages. The demo owner configures its Kokoro connection through environment variables. Demo sections remain limited to 20,000 characters for narration.

After a synchronization error, choose **Retry book audio** without **Replace existing recordings**. Langy rebuilds sections whose cached recordings have no usable timestamps while reusing valid sections.

```bash
  -f compose.yaml -f compose.tunnel.yaml up -d --build --no-deps language reader
```

For the personal stack, use `sudo docker compose up -d --build --no-deps language reader`.

The server checks due jobs in the background, requests a fresh member URL for each retry and preserves the queue across restarts. Authentication errors, invalid files and size-limit failures require fixing their cause. Slow downloads still respect browser verification; a final signed link is never saved for reuse six hours later. Turn retries off in Book sources or cancel a waiting job to stop its automatic attempts.

In [Cloudflare Tunnels](https://one.dash.cloudflare.com/), add a [published application route](https://developers.cloudflare.com/tunnel/get-started/) for `langy.srtw.win`. If the existing tunnel runs on the same host as the demo, set its HTTP service URL to `http://127.0.0.1:8089`.

If you need a new tunnel connector in Docker, create a Cloudflare Tunnel and point the published route to `http://reader:8080`. From the repository directory:

1. Create the private directory with `install -d -m 700 .secrets`.
2. Save the tunnel token by itself in `.secrets/tunnel-token`, then run `chmod 444 .secrets/tunnel-token` so the connector can read its mounted copy.
3. Start the connector and demo together.

```bash
docker compose --env-file .env.demo -p langy-demo \
  -f compose.yaml -f compose.tunnel.yaml up -d --build
```

Once the tunnel is healthy, open [langy.srtw.win](https://langy.srtw.win), open the sample book and press **S**. The first answer can take longer while the model loads.

## Thesaurus sources

The Docker build indexes [Princeton WordNet 3.0](https://wordnet.princeton.edu/), the human-built dictionaries in [Open Multilingual Wordnet 1.4](https://omwn.org/omw1.html), and selected senses and forms from the [Spanish Wiktionary contributors](https://es.wiktionary.org/) via [Kaikki’s Wiktextract export](https://kaikki.org/eswiktionary/rawdata.html). The Wiktionary index, including abbreviated glosses, is distributed separately under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Source licenses and citations are retained under `server/thesaurus-data/licenses/`. The reading notes carry their sources in `server/reading-lexicon.js`. For a build outside Docker, run `npm run build:thesaurus` to download and index the same dictionaries.

In **Import book**, optionally enable **Automatically generate an audiobook if none exists** and choose a delay of 1–10,080 minutes (10 initially). The choice applies to that import or each book in an Anna’s Archive batch. The timer starts after the book reaches the library and survives server restarts. Generation waits for Kokoro, text analysis and an available slot. An existing uploaded recording or generation attempt prevents a duplicate; failed jobs require a manual retry. Cancel a waiting schedule in the book’s Audio tools. Finished recordings can then export automatically to the explicitly mapped Audiobookshelf category.

Saved API keys in Settings have **Remove saved API key** buttons. Each button asks for confirmation before removing only that service’s stored key; other settings are retained. The Anna’s Archive membership key uses the same confirmation flow.

### Reader workflow updates

The **Process queue** at the bottom left brings server downloads, analysis, reading estimates, OCR, narration, alignment repair and Audiobookshelf transfers together with device book-pack downloads. Open a job’s Details to continue in its book tools; Anna’s Archive jobs retain their retry and slow-download controls. Slow browser requests appear while they run. In the queue, choose **Auto-dismiss completed tasks after (minutes)**. The default **0** clears completed/cancelled tasks immediately; a positive delay keeps them visible for that many minutes after completion. The preference syncs with the reader’s account. Errors and audio replacement approvals stay available until acted on. Downloaded books remain in the library. You can browse and read while work continues. Device downloads still need Langy open; server jobs run independently.

Anna’s Archive download entries use a supplied title, structured metadata when the existing key has permission, the public edition heading, or a readable download filename. Metadata requests never call the fast-download endpoint or consume download allowance. The optional key is sent only to the selected AA mirror's metadata endpoint, with redirects disabled; it is not sent to public-page or file hosts for title lookup. AA can block public pages with DDoS-Guard, and ordinary download membership does not necessarily grant metadata API access. Failed lookups retry with backoff, preserve their retry time across restarts, and report a safe reason without exposing keys or signed URLs. **Retry title lookup** retries metadata independently of the download. **Set title** names an existing queued import without cancelling it, using another fast-download allowance or changing its queue position. Discovered and manually supplied names survive restarts. The slow-download notice and continuation action remain with the corresponding book, without a duplicate notice above **Book downloads**.

Server background workers share one slot across all users: downloads, text extraction, vocabulary analysis, reading estimates, OCR, narration, audiobook synchronization, alignment repair, book discovery and Audiobookshelf transfers run one task at a time. Priority changes switch work at the next safe stopping point. The queue shows **Switching after the current step** while the active job reaches that point, then **Paused for higher-priority work** while it waits to continue. Reading, playback, settings and interactive word/page explanations remain available.

Analysis and narration pause between passages and retain completed work during the live session. Partial web and Anna’s Archive downloads restart when their turn returns; temporary downloads are discarded before another transfer starts. iVoox yields between episodes, and discovery yields between stages. Remote OCR requests, Audiobookshelf uploads and final file publication finish their current atomic operation before switching.

Library books show **Audio synced** when a complete generated or imported recording has finished alignment against the current book text. The label also appears in the quiet library and covers-only views. Uploaded files that still need synchronization do not receive the label. Existing saved alignments are recognized after upgrading or restarting, and the label clears when no compatible synced recording remains. Some word positions may still be estimated; the label indicates the recording is ready for synchronized reading. The desktop Process queue launcher rests as a square icon with its status badge and expands on hover or keyboard focus.

Ready Anna’s Archive downloads start ahead of other server tasks by default, marked **Anna’s Archive priority**. Manual priority controls override that default, including existing overrides saved before an update or restart. Downloads waiting for their retry time or user action do not block work that is ready to run.

Use **Raise priority** to move a task ahead of the running task while preserving work already ranked above it, **Top priority** to move ahead of all other tasks, or **Lowest priority** to move behind them. These controls work on running and queued jobs. With no active task, Raise priority moves to the top. Queue positions include the running task, so the requested order remains visible while a switch is pending. Manual queue order survives server restarts, and required text extraction runs before a promoted task that needs it. Prerequisites inherit that priority unless explicitly set to **Lowest priority**, which also delays the tasks that depend on them. A task waiting for a connection, retry time or approval still needs that condition resolved. Shared-book recipients cannot reorder the owner’s work.

Android book-pack downloads have their own single-device queue with the same three priority controls. Switching safely stops the current transfer and returns it to the queue; it restarts when its turn returns. A completed offline pack remains available until a complete replacement is saved. Device queue order survives closing the app, and device transfers can run while the server processes a book.

Pinch EPUB text with a desktop trackpad to change the desktop font size; phone/tablet size remains separate. Plain arrow keys turn pages; **Ctrl+Left / Ctrl+Right** jump between sections. Select a phrase and choose the explain icon or press **E** for its meaning in context, in your translation language. Long explanations scroll inside the popup. **Search the web** appears in the explanation and queries the configured search service using up to 220 characters of the selection. The model uses the surrounding passage and relevant search excerpts, with links to the cited sources. If the search fails or finds no helpful sources, the first explanation remains visible. On an existing Compose installation, start the bundled provider with `sudo docker compose up -d --build --no-deps search`. If you use a different SearXNG instance, check `READER_SEARCH_URL` and enable JSON in its search formats. Explanations from the passage alone follow your **Save and reuse AI answers** preference.

Mandarin pinyin passages are saved with each book in the persistent data directory and reused across sessions and devices. Exact surrounding text and pronunciation-data revisions identify reusable results. The cache fills as you read; changed text or updated pronunciation data gets fresh readings. Offline packs also save locally generated pinyin on the device. Pinyin is dictionary based and uses no LLM tokens.

Choose **View** in the library for automatic sizing, 1, 2, 3 or 4 columns, or a list. **Covers only** hides text beneath covers; the normal view shows an EPUB/PDF label beneath each cover. These choices sync per account. On touch devices, tap the definition popup’s text to cycle available dictionary meanings or Mandarin word/character cards.

Account menus and **Settings → Account** offer **Log out** and **Switch user**. Both revoke the current server session and clear this account’s downloaded books and local reading data from the device before returning to sign-in; the server library stays saved. A server connection is required to revoke the session.


## Free book sources and web imports

Choose **Import book → Web link / free book catalogues**. Paste a direct public HTTPS EPUB or PDF download link, or search Project Gutenberg by title/author and select **Use this EPUB**. Review the folder, language and optional delayed audiobook generation before importing. Catalogue metadata comes from [Gutendex](https://github.com/garethbjohnson/gutendex); acquisitions come from Gutenberg and are filtered to works listed as public domain in the US. The prompt also links to [Standard Ebooks](https://standardebooks.org/ebooks) and [OAPEN](https://library.oapen.org/) for choosing downloads. Website pages, login-protected/DRM downloads, private-network URLs and oversized files are rejected. You can always download a file yourself and use **Upload file**.

Web downloads persist in Processes through server restarts, belong to the requesting account, and use the same folder assignment and storage limits as file uploads. Cancel pending downloads with their **×**; retry a failed download from Processes. A completed file’s final save cannot be cancelled. The queue does not bulk scrape catalogues.

## Automatic cover search

**Import book** and **Book details** have **Find covers automatically**, which searches the entered title and author. The default **Automatic · no key required** combines [Open Library](https://openlibrary.org/dev/docs/api/search) and Google Books, and keeps available results if one source fails. Each result links to its source edition. You can choose either provider directly. Choose **Use this cover**, then save the book; Open Library and Google covers work with Langy’s cover cache and offline packs. Existing covers are preserved until a replacement succeeds.

A [Google Books API key](https://developers.google.com/books/docs/v1/using#APIKey) in **Settings → Book sources → Cover search** is optional. If supplied, Langy uses it for Google searches. Restrict it to the Books API and the server’s public outbound IP; website-referrer restrictions do not match these server requests. Anonymous Google requests can be quota-limited. Repeated identical searches are cached per account for ten minutes and do not consume another search slot. Ten new searches per account per minute remain allowed, with provider cooldowns after quota responses. Cover searches and library recommendations share Open Library’s conservative request pacing. No shared project key or paid cover service is bundled.

The optional Amazon search uses the current [Creators API](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/onboarding/register-for-creators-api), not the retired PA-API. It requires an approved Associates account, client ID/secret, credential version, marketplace and Partner Tag. Credentials stay on the server in a private file; OAuth tokens are reused until expiry. Amazon results are temporary previews linked to their source edition, rather than permanently saved/offline API images. Use Open Library, Google Books or an independently supplied image URL for stored covers. Search previews are account-scoped and expire after ten minutes. Provider failures do not change the book’s cover.

## Downloading free fonts

In **Settings → Appearance → Imported fonts → Download a free font**, search Google Fonts via [Fontsource](https://fontsource.org/), choose a family, language subset, weight and style, and download it. Save settings to apply it. A subset contains only its listed characters; missing scripts use Langy’s built-in fallback. Segmented CJK variants may require importing a complete TTF/OTF from the official source instead. Alternatively, paste a direct font-file link from Google Fonts’ `fonts.gstatic.com`, Fontsource’s jsDelivr packages, or the official `google/fonts` / `notofonts/noto-cjk` repositories. Every redirect must stay on an allowed source. ZIPs are not accepted. Format checks, account privacy, storage limits and offline font caching are the same as uploaded fonts; source information is retained with the font.

## Cancelling processes

Active Processes cards and device downloads have a small **×**. Cancellation stops queued work and aborts running network requests when supported. The source book and existing saved audio remain. Cancelled OCR cannot replace the original PDF, and a cancelled analysis/alignment cannot publish a late response over current data. Recipients cannot cancel an owner’s shared-book work. An interrupted ABS upload is held for review because ABS may already have received files; it is not automatically uploaded again. An approved local-audio replacement keeps its existing confirmation step.

## Web and Android controls

Shared reading, audio, pinyin, book tools, imports, folder mappings, account settings and process controls use the same application in web browsers and Android. Every book has a Book options menu on desktop as well as mobile, including the covers-only layout. Offline book packs, their download queue and the option to remove downloaded packs when switching users are available only after the Android app’s native connection is established. A mobile browser or installed web shortcut is still the web version. Standard book and MP3 file downloads remain available in browsers. Existing cached books are preserved when controls change.

Process queue consolidates superseded failures for the same book and operation. Dismissed failures stay dismissed on that browser after reloading; a new failure or retry remains visible. Active tasks and replacement approvals are retained. Completed task timing continues to follow the selected auto-dismiss preference.
