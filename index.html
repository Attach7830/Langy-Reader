About Langy Reader

Langy Reader helps language learners read EPUBs and PDFs. Hover over a word or tap it for a translation, definition, or synonyms. Press S for a brief page summary. Select Go deeper or a suggested question for more context.

Using the demo

Try the sample book or upload up to four books at 20 MiB each. Your uploads are private to this browser session and expire after 24 hours. Translations and summaries can take longer on the shared AI server.

Use the headphones button to preview narration and podcast controls. Kokoro is optional: connect it in your self-hosted installation to generate and download whole-book audio.

Run your own copy

Self-host Langy Reader with Docker Compose. For faster translations and summaries, connect your AI server in Settings → AI connection.

Kokoro connection

Uses language-specific Kokoro voices for mixed books. Your TTS server must provide those voices. Set overrides below for your server; Portuguese voice presets use Brazilian Portuguese.

Anna’s Archive

Connect Anna’s Archive on your self-hosted installation. This public demo does not store membership keys or download books from external sources.

This connection applies to this installation. The key is saved on your server and is never returned by the settings API. Membership eligibility and download limits still apply.

Save the connection, then choose Anna’s Archive in Import book and paste a book link or MD5. Import supports EPUB and PDF within the normal size limit.

OPDS library

Browse and download your books on an OPDS reader. On Xteink with CrossPoint firmware, open Settings → Connectivity → OPDS Servers → Add Server.

OPDS is available on your self-hosted installation. This demo does not publish visitors’ books in a shared catalog.

Use an address your reader can reach on Wi-Fi. A localhost address only works on the server itself. HTTPS is recommended when connecting outside your home network.

EPUBs are listed first, with categories, title/author search and recent additions. PDFs have a separate catalog and may need conversion for Xteink. Downloads use the original book file.

OPDS transfers books. Enable reading progress sync below to resume between Langy and a compatible reader. Langy’s AI summaries and synced audio remain in the web reader.

Reading progress sync

Connect your readers on a self-hosted installation. Sync is disabled in this demo to keep visitors’ reading progress private.

On CrossPoint, open Settings → Connectivity → CrossPoint Sync. Choose server type KoSync, enter this sync address and your credentials, then authenticate. While reading, open the reader menu and select Sync Progress before switching devices.

Use Binary/content document matching and download the same EPUB from OPDS. A converted or edited copy will have a different sync ID. On KOReader, set this custom server in Progress sync and log in with the configured account; do not register a new account.

Langy resumes saved progress when you open a book. If another device changes it while you are reading, choose which position to keep. Offline progress stays on this browser until it reconnects. Unsupported EPUB locations use an explicitly labelled approximate position.

This syncs reading position only. Bookmarks, notes and audio playback time are not transferred.

Import book

Uses the membership key saved in Settings → Book sources. EPUB or PDF, up to 120 MiB. The download continues on the server if this dialog is closed.

EPUBs use their metadata when available. Otherwise the default is Spanish.

Analysis, word help and narration use only these languages. If the primary language is excluded, the first selection becomes primary. Saving reanalyzes the existing book.

Leave language selection off for automatic passage detection.

Reading vocabulary

Includes tracked reading and books marked read. Marking a book read adds inferred exposures for one full reading, filling only the parts not already tracked. Marking it unread removes those inferred exposures and keeps tracked reading. Mandarin characters and each language’s lemmas remain separate.

Each word occurrence counts once per reading session. Page redraws do not add exposures; reopening a book to reread it starts a new session. The default of 20 is adjustable and is not a validated mastery cutoff.
